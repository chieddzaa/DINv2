How a task window works

At the scheduled time DIN sends a start nudge. 10 min later, if nothing's happened, a delay nudge. After 30 min the window closes: the task is marked missed, and the next task gets a recovery prompt.

Every message is chosen by the tone algorithm: moment (start, delay, miss, done, recovery) × execution profile × DIN tier.

MVP scope

Data is saved in this browser only. The production build connects this front end to the Supabase database and Fastify API, with real push notifications on iOS and Android.
